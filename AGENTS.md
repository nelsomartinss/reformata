# Reformata

**A fé reformada em seus textos.** Leitor web gratuito dos principais documentos da
tradição reformada, com as passagens bíblicas sempre à mão. Não exige cadastro e evita
termos técnicos, para que até quem nunca leu um catecismo consiga navegar.

O texto bíblico fica em JSON no próprio repositório: o site não depende de API externa
para mostrar as Escrituras.

## Comandos

| Comando | O que faz |
|---|---|
| `npm run dev` | Servidor de desenvolvimento. |
| `npm run build` | Build de produção. |
| `npm run lint` | Verificação de código. |
| `npm run format` | Formatação. |
| `npm run validate:content` | Confere a estrutura dos documentos. |
| `npm run test:references` | Confere se as referências bíblicas abrem o texto certo. |
